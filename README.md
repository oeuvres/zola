# Émile Zola

Cette collection de textes TEI normalisés vise à couvrir le cycle des Rougon-Macquart. Ces fichiers ont été réunis à fin d’expériences de textométrie, ce n’est pas une édition complète et relue. Les textes ne sont pas originaux mais repris de différents sites de livres électroniques libres et gratuits.
